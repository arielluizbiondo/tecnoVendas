# Tecno Vendas - Projeto

Sistema simples de **gerenciamento de vendas** desenvolvido com **PHP, MySQL e Bootstrap** para fins de estudo e prática em desenvolvimento web.

O projeto simula um pequeno sistema de vendas, permitindo **cadastro de usuários, autenticação, cadastro de produtos e registro de vendas**.

---

## 🚀 Funcionalidades

✔ Cadastro de usuários  
✔ Sistema de login com controle de acesso  
✔ Cadastro de produtos  
✔ Consulta de produtos disponíveis  
✔ Registro de vendas  
✔ Cálculo automático do valor total da venda

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos importantes de desenvolvimento web, como:

* conexão com banco de dados
* criação de funções em PHP
* manipulação de dados com SQL
* controle de sessões
* autenticação de usuários
* construção de interfaces simples com Bootstrap
